Как пользоваться

Тетрадь разрешена на экзамене. По главе на полстраницы: формулы с единицами, ключевые числа и один решённый пример. Подпишите края: ЕДИН, МЕХ, ВРАЩ, ПРОЧ, ЖИДК, ПОТОК, МОЛ, ТЕРМО, ЗВУК, ЭЛЕКТ, ЭКГ. Алгоритм задачи: выписать «дано» в СИ → найти формулу здесь → подставить → проверить единицы.

МЕХ — Ch. 1–3: векторы, статика, движение

  • sin θ = прот./гип.; cos θ = прил./гип.; tan θ = прот./прил. Aₓ = A cos θ, Aᵧ = A sin θ.
  • v = v₀ + at; x = v₀t + ½at²; v² − v₀² = 2ax.
  • F = ma; w = mg; W = Fd cos θ; KE = ½mv²; PE = mgh; P = W/Δt.
  • Равновесие: ΣF = 0 и Στ = 0; τ = F·d (d — плечо).
  • Рычаги: 1-го рода — ось посередине (голова на атланте); 2-го — груз посередине (на носки); 3-го — сила посередине (бицепс), самый частый в теле.
  • Локоть: F_мышцы·d_мышцы = W_груза·d_груза + W_предпл·d_цм.
  • Трение F = μN; μₛ > μₖ; в суставах μ ≈ 0,003–0,01.
  • Прыжок вверх: h = v²/2g. Прыжок в длину: R = v² sin2θ / g, максимум при 45°: R = v²/g.
  • Бег: энергия на шаг E = mv²; КПД мышц ≈ 20%. Толкать стену — работа = 0.

Пример (локоть): груз 50 N на 0,35 m, бицепс на 0,04 m, предплечье не учитываем → F = 50·0,35/0,04 = 437,5 N (в 8,75 раза больше груза).

ВРАЩ — Ch. 4: вращение и маятник

  • ω = Δθ/Δt; v = ωr; a = v²/r = ω²r.
  • τ = Iα; I = Σmr²; стержень вокруг конца I = ml²/3; E_вращ = ½Iω²; L = Iω.
  • Поворот: F = mv²/R; наклон tan θ = v²/(gR).
  • Маятник: T = 2π√(L/g); нога (стержень): T = 2π√(2L/3g); f = 1/T.
  • Гармоника: x = A sin ωt; v_max = Aω; a_max = Aω².

Пример: нога L = 0,9 m → T = 2π√(2·0,9/(3·9,8)) = 2π·0,247 = 1,55 s.

ПРОЧ — Ch. 5: упругость, удар

  • Напряжение S = F/A (Pa); деформация St = Δl/l; Гук: S = Y·St; k = YA/l; F = kΔl.
  • Энергия деформации E = ½kΔl².
  • Удар: F = Δp/Δt = m(v_f − v_i)/Δt — чем дольше удар, тем меньше сила.
  • Падение: v = √(2gh); F = m√(2gh)/Δt. Подушка: F = mv²/(2s).
  • Кость вязкоупругая: быстрая нагрузка — прочнее. Сухожилия: «toe region».

Пример: 70 kg падает с 0,5 m, остановка за 0,01 s → v = √(2·9,8·0,5) = 3,13 m/s; F = 70·3,13/0,01 ≈ 21 900 N.

ЖИДК — Ch. 7: жидкости в покое

  • P = F/A; P₂ − P₁ = ρgh.
  • Паскаль: F₁/A₁ = F₂/A₂; выигрыш M = A₂/A₁.
  • Архимед: F_B = ρ_ж·g·V; плавает, если средняя плотность < ρ воды.
  • Поверхностное натяжение T = F/L (N/m); капилляр h = 2T cos θ / (Rρg).
  • Лаплас: ΔP = 2T/R (альвеола) — сурфактант снижает T, мелкие альвеолы не спадаются.

Пример: разница давлений между головой и стопами (h = 1,7 m, ρ = 1060 kg/m³): ΔP = 1060·9,8·1,7 = 17 660 Pa ≈ 133 mmHg.

ПОТОК — Ch. 8: кровоток

  • Непрерывность: Q = A·v = const — в сужении v растёт.
  • Бернулли: P + ½ρv² + ρgh = const — в стенозе давление на стенку падает.
  • Пуазёйль: Q = πR⁴ΔP / (8ηL); сопротивление Re = 8ηL / (πR⁴). Радиус вдвое меньше → поток в 16 раз меньше.
  • Рейнольдс: Rₙ = ρvR/η (для сосуда — диаметр); > ~2000 — турбулентность, шумы.
  • BP = Q × сопротивление; CO = HR × SV; норма 120/80 mmHg.
  • Мощность сердца P = Q·(ΔP + ½ρv²).

Пример: HR 70/мин, SV 70 ml → CO = 4,9 l/min.

МОЛ — Ch. 9: молекулы и диффузия

  • Кулон F = k·q₁q₂/r². Нековалентные связи: электростатические, водородные, ван-дер-ваальсовы (лондоновские), гидрофобные.
  • Лёд — сетка H-связей с полостями, поэтому легче воды.
  • Диффузия: ⟨x²⟩ = 2Dt (1D), ⟨r²⟩ = 4Dt (2D), 6Dt (3D).
  • Стокс ξ = 6πηR; Эйнштейн: D = k_B T / (6πηR) — мелкие молекулы быстрее.

ТЕРМО — Ch. 10–11: тепло и энергия

  • 1-й закон: ΔU = Q − W. Q = cmΔT. КПД = 1 − T₂/T₁.
  • 2-й закон: ΔS > 0; живое держит порядок за счёт энергии пищи.
  • Информация I = log₂Ω бит; Больцман S = k_B ln Ω; Шеннон H = −KΣPᵢ ln Pᵢ.
  • Фрактальная размерность D = log N / log S (Кох 1,26; лёгкие 2,97; мозг 2,79).
  • Площадь тела = 0,202·M^0,425·H^0,725; основной обмен ∝ M^3/4 (Клайбер).

ЗВУК — Ch. 12: звук и слух

  • f = 1/T; v = fλ; ω = 2πf; k = 2π/λ; v = √(B/ρ).
  • I = P/A (W/m²); β = 10 log(I/I₀) dB, I₀ = 10⁻¹² W/m².
  • Резонанс fₙ = nv/2L; слуховой проход ~3000 Hz. Биения f_b = |f₁ − f₂|.
  • Импеданс z = ρv; воздух/вода — 99,9% отражается → гель при УЗИ.
  • Слух 20–20 000 Hz; усиление: проход ×2, перепонка ×30, косточки ×2. Эхолокация d = vt/2.

Пример: I = 10⁻⁶ W/m² → β = 10 log(10⁶) = 60 dB. Удвоение I → +3 dB.

ЭЛЕКТ — Ch. 13: электричество и нервы

  • E = F/q; V = W/q; Ом: V = IR; R = ρL/A; P = IV = I²R; C = Q/V = ε₀A/d; E = ½CV².
  • Покой ≈ −70 mV; внутри больше K⁺, снаружи Na⁺. Нернст: ΔV = (k_B T/q) ln(c₁/c₂).
  • ПД: Na⁺ внутрь (деполяризация) → K⁺ наружу (реполяризация); до 100 m/s.
  • Ходжкин–Хаксли: I = C_m dV/dt + g_K(V − V_K) + g_Na(V − V_Na) + g_L(V − V_L).
  • Кабель: V = V₀ e^(−x/λ); без миелина λ ≈ 0,8 mm, с миелином ≈ 16 mm; сальтаторное проведение в перехватах Ранвье.
