Как пользоваться

ОПИС — описательная статистика

Что Формула / правило Когда
Mean x̄ = Σx / n симметричные данные
Median середина упорядоченного ряда выбросы, асимметрия
Mode самое частое значение категории
Range max − min грубый разброс
IQR Q3 − Q1 разброс без выбросов
Variance s² = Σ(x − x̄)² / (n − 1) разброс
SD s = √s² разброс в единицах данных
Covariance cov = Σ(x − x̄)(y − ȳ) / (n − 1) > 0 — растут вместе

Пример (лекция): 10, 12, 15, 15, 18, 18, 18, 22, 27, 30 → mean 18,5; median 18; mode 18; range 20; IQR = 22 − 15 = 7.

Пример s²: САД 120, 130, 110, 140, 115 → x̄ = 123; Σ(x − x̄)² = 580; s² = 580/4 = 145; SD ≈ 12,0 mmHg.

Переменные: количественные — continuous / discrete; категориальные — nominal (без порядка) / ordinal (с порядком). Parameter (μ, σ) — популяция; statistic (x̄, s) — выборка.

Графики: pie — доли; bar — категории; histogram — распределение чисел; boxplot — медиана, квартили, выбросы.

ТЕСТЫ — нормальное распределение и гипотезы

  • Normal: mean = median = mode; правило 68–95–99,7% (±1, ±2, ±3 SD).
  • z = (x − μ) / σ. Positive skew: mean > median; negative: mean < median.
  • H₀ — нет эффекта; α = 0,05; p < α → отвергаем H₀.
  • Type I (α) — отвергли верную H₀; Type II (β) — не отвергли ложную.
Тест Когда Формула
z-test n большое, σ известна z = (x̄ − μ) / (σ/√n)
t-test n < 30, σ неизвестна t = (x̄ − μ) / (s/√n), df = n − 1
χ² категориальные, независимость χ² = Σ(O − E)² / E
ANOVA (F) 3+ средних F = между группами / внутри групп

χ² — как считать E: E = (сумма строки × сумма столбца) / общий итог.

2×2 — дизайны исследований, RR, OR

Дизайн Как Мера
Cross-sectional экспозиция и исход одновременно prevalence
Case-control от болезни назад к экспозиции OR
Cohort от экспозиции вперёд к болезни incidence, RR
RCT случайное распределение RR, разница исходов 
                Болезнь +   Болезнь −
Экспозиция +       a           b
Экспозиция −       c           d
  • RR = [a/(a+b)] / [c/(c+d)] — когорта, RCT.
  • OR = (a·d) / (b·c) — case-control.
  • = 1 — связи нет; > 1 — фактор риска; < 1 — защитный.

Пример: a = 30, b = 70, c = 10, d = 90 → RR = 0,30 / 0,10 = 3,0; OR = (30·90)/(70·10) = 3,86.

Клиническая польза: ARR = риск_контроль − риск_лечение; RR = риск_лечение / риск_контроль; RRR = 1 − RR; NNT = 1 / ARR. Пример: контроль 20%, лечение 15% → ARR = 0,05; NNT = 20.

Bias: case-control — recall bias; cross-sectional не показывает, что было раньше. Texas sharpshooter — видим только сходства.

РЕГР — корреляция и регрессия (Lec 2)

  • Простая линейная: y = β₀ + β₁x; β₁ = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)²; β₀ = ȳ − β₁x̄.
  • Pearson R от −1 до +1: знак — направление, модуль — сила.
  • R² = 1 − RSS/TSS — доля объяснённой дисперсии (R² = 0,17 → 17%).
  • Linear — непрерывный исход; logistic — бинарный: log(p/(1−p)) = β₀ + β₁x; OR = e^β₁.

Пример cov: ИМТ 22, 28, 26, 30, 24 и холестерин 180, 200, 195, 210, 190 → cov = 140/4 = 35 (положительная связь).

KM — выживаемость (Lec 3)

  • S(t) = P(T > t). Censoring — событие не наблюдали (выбыл, конец исследования).
  • Kaplan–Meier: S(t) = S(пред) × (1 − d/n). Цензура уменьшает n, но не S.
  • Hazard h = d/n в момент события. H(t) = Σh; S(t) ≈ e^(−H).
  • Log-rank: H₀ — кривые одинаковы; χ², df = 1.
Месяц n под риском d 1 − d/n S(t)
3 5 1 4/5 0,80
5 цензура — — 0,80
8 3 1 2/3 0,53
12 2 1 1/2 0,27

Hazard: 20% (3 мес), 33% (8 мес), 50% (12 мес).

ВАЛИД — валидация моделей (Lec 4)

                Болен (факт)   Здоров (факт)
Тест +              TP              FP
Тест −              FN              TN
Метрика Формула Смысл
Accuracy (TP + TN) / все доля верных
Sensitivity (recall, TPR) TP / (TP + FN) находит больных
Specificity (TNR) TN / (TN + FP) не трогает здоровых
Precision (PPV) TP / (TP + FP) верность «+»
NPV TN / (TN + FN) верность «−»
F1 2·P·R / (P + R) > 0,9 отлично; < 0,5 плохо
Youden J Sens + Spec − 1 лучший порог — max J
FPR FP / (FP + TN) = 1 − Spec ось X на ROC

Пример: TP 40, FP 10, FN 20, TN 130 → Sens = 40/60 = 0,67; Spec = 130/140 = 0,93; PPV = 40/50 = 0,80; Acc = 170/200 = 0,85; F1 = 2·0,80·0,67/(1,47) = 0,73; J = 0,60.

ROC: Sens против 1 − Spec; AUC 0,5 — случайно, 1,0 — идеально (лекция: 0,76).

AI — AI в медицине и классификация

  • Уровни: ANI (одна задача), AGI (как человек), ASI. Ограничения: галлюцинации, bias, приватность, ответственность.
  • Промпты: zero-/one-/few-shot, chain-of-thought, tree-of-thought, ReAct, role, RAG, iterative, re-reading.
  • RAG: retrieval → augmentation → generation.
  • 3C: Concise, Clear, Context. RTCC: Role, Task, Context, Constraints. PROMPT: Provide context, Refuse unsafe, Omit unverified, Mandate references, Prioritize guidelines, Transparent limitations. SOAP: Subjective, Objective, Assessment, Plan.
Метод Суть
Decision tree разбиения от корня к листьям; pruning против overfitting
Gini 1 − Σp² (0 — чисто; 0,5 — максимум для 2 классов) → берём наименьший
Entropy −Σp log₂p; IG = S(parent) − Σ(nᵢ/N)·S(child) → берём наибольший IG
SVM гиперплоскость с максимальным margin; support vectors
KNN класс по большинству k соседей
K-means unsupervised, k кластеров
CNN изображения: рентген, КТ, дерматоскопия

Пример Gini: узел 6 больных + 4 здоровых → 1 − (0,6² + 0,4²) = 1 − 0,52 = 0,48. Пример IG (лекция): «energy» IG = 0,99 − 0,62 = 0,37.

БИО — биоинформатика (Lec 5–9)

  • Базы: первичные — GenBank, EMBL, DDBJ (нуклеотиды), UniProt (белки), PDB (структуры); форматы GenBank, FASTA (строка «>»), PDB.
  • Identity — одинаковые остатки; similarity — похожие; homology — общее происхождение (да/нет).
  • I% = 2Li / (La + Lb) × 100; S% = 2Ls / (La + Lb) × 100.
  • Needleman–Wunsch — глобальное; Smith–Waterman — локальное (минус → 0).
  • PAM (PAM1 = 1% замен; больше номер — дальше родство); BLOSUM62 — стандарт (меньше номер — дальше).
  • BLAST: seed (W-mers) → расширение → E-value (меньше — лучше). BLASTP, BLASTN, BLASTX, TBLASTN.
  • MSA: sum of pairs; Clustal Omega, MUSCLE, MAFFT, T-Coffee. PSSM — log-odds по позициям. HMM: match, insert, delete. UPGMA — объединять ближайших, среднее расстояние.
  • Мотив — короткий консервативный участок; домен — независимо сворачивающаяся единица (Pfam, PROSITE).
  • Структура белка: первичная → вторичная (α-helix, β-sheet) → третичная → четвертичная. Ramachandran — углы φ, ψ. Методы: X-ray, NMR, Cryo-EM; AlphaFold.
  • Геномика: структурная, функциональная, эпигеномика, сравнительная (ортологи — между видами, паралоги — внутри). Секвенирование: Sanger (обрыв цепи), Maxam–Gilbert, пиросеквенирование, NGS (300–500 bp).

Источник: конспект AI и биостатистики в Plastic Path (Lec 1–10). Примеры RR/OR, NNT, валидации и Gini составлены для тренировки.
